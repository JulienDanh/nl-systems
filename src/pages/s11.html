System 11 — Hero Calling

Systematically differentiating between bluff catchers on the river.

Three keys

#KeyDescription
1Range awarenessKnow what combos you arrive with
2Unblock bluffsPrefer hands that don't block opponent's bluffing region
3Block valuePrefer hands that block opponent's value region
Value range wide → focus on #2 (unblock bluffs). Narrow → focus on #3 (block value).

Core principle

Opponent's required bluff frequency = your pot odds. Need 25% → they must bluff 25% of betting range. If balanced → worst callable = worth 0. But better bluff catchers (block value / unblock bluffs) = worth significant EV.

AttributeGoodBad
Blocks value✅ King (blocks KK, KQ)❌ 8/9 (blocks nothing valuable)

Preflop awareness: BTN opens suited 5+ and offsuit 8+. 4-x/3-x unblock bluffs (not opened); 8-x/9-x block bluffs (opened).

Exceptions

  • Recreational players may bluff with too-strong hands → higher kickers marginally better.
  • Check-raise opportunity: if opponent bets too small IP (1/3 pot, thin value), CR second pair can fold better + call worse.
  • No natural bluffs: if no draws missed, opponent won't convert Ax to bluff → fold even if MDF says call.

CR sizing

Modest CR (to ~25bb) can get hands you beat to call (KQ, QJ) and hands that beat you to fold (A-3/4/5♥).

Hand Examples

CR
QT2 → A → blank · A♥3♥ (second pair) · IP bet 1/3

System: Range dense with KQ/QJ (12 combos) vs A-3/4/5♥ (3 combos). CR to ~25bb.

Solver: May fold better (A-x hearts) and call worse (KQ, QJ).

Fold
6xxx → 6 makes straight · A-J suited · BB overbet small

System: Opponent won't bluff with A-2/3/4/5. No natural bluffs. Fold.

Solver: Lost to A-7 (thin value, not 6-bluff). No natural bluffs available.

Call (blocker)
T42 → J (checked) → blank · T6o · IP bet ¼

System: T-6 blocks pair of tens (value region). Call.

Solver: Lost to K-T but correctly identified value source.

Blocker call
A72 → blank (turn checked) → Q♠ · K7/42/43 · IP bet 37.5%

System: Call K7/K3/K2, 42/43/74; fold 87/82/97/92.

Solver: K-x blocks value (KK/KQ); 4-x unblocks bluffs; 8/9-x block bluffs. Confirmed.

Toy game
22237, SPR 1x · 88 vs 87s · OOP jams pot

System: 88 = worth 0 (indifferent); 87s = ~27% pot. 87s blocks 77 (value, removes ⅔ of value combos) and unblocks JTs (bluff).

Lesson: Not all bluff catchers are equal.
